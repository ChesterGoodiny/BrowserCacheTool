# Browser Cache Tool

Утилита для Windows 10/11, которая блокирует и разблокирует запись в безопасные кэш-папки браузеров. Поддерживаются Google Chrome, Microsoft Edge, Brave, Vivaldi, Chromium, Яндекс Браузер, Mozilla Firefox и Opera.

Программа использует ACL по встроенному SID `S-1-1-0`, не зависит от языка Windows и требует запуска с правами администратора.

## Запуск из исходников

Требуется Python 3.11+ и Windows. Установите зависимости и запустите консолью:

```bat
python -m pip install -r requirements.txt
python main.py
```

Программа должна быть запущена от имени администратора. В интерфейсе выберите браузер и при необходимости включите очистку содержимого перед блокировкой. По умолчанию существующие данные сохраняются.

## Сборка EXE

Запустите `build.bat`. Скрипт установит runtime- и build-зависимости, а готовый файл появится в `dist\BrowserCacheTool.exe`. PyInstaller добавляет manifest с требованием администратора.

Для запуска тестов без изменения профилей браузеров:

```bat
python -m unittest discover -s tests -v
```

## Важно

Перед операцией приложение принудительно закрывает процессы выбранного браузера текущего пользователя. Сохраните данные в открытых вкладках. Программа работает только с кэш-папками: `Cache`, `Code Cache`, `GPUCache`, `Service Worker\CacheStorage` для Chromium-браузеров и `cache2` для Firefox. `IndexedDB` не трогается.

Очистка кэша может привести к повторной загрузке ресурсов сайтами. Локальные данные сайтов намеренно не удаляются.

Лог сохраняется в `%LOCALAPPDATA%\BrowserCacheTool\browser_cache_tool.log`.

## Ограничения

- Поддерживается только Windows 10/11.
- `IndexedDB`, cookies, историю, пароли, закладки, расширения и настройки программа не изменяет.
- Операция закрывает процессы выбранного браузера текущего пользователя. Если процесс не удалось закрыть, операция останавливается до изменения файлов и ACL.
- Проект не подписан цифровым сертификатом; Windows SmartScreen может показать предупреждение для локально собранного EXE.

## Публикация релиза

GitHub Actions автоматически проверяет код и может собрать EXE. Сборка запускается вручную через `workflow_dispatch` или автоматически для тегов вида `v1.0.0`; готовый файл публикуется как artifact `BrowserCacheTool-windows`. Для локальной сборки используйте `build.bat`. Папки `build/`, `__pycache__/`, локальные логи и промежуточные сборки исключены через `.gitignore`.
