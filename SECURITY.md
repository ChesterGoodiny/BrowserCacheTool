# Security Policy

## Reporting a vulnerability

Do not publish working exploit details in a public issue. Please use GitHub Security Advisories for this repository, or contact the repository owner privately.

Include:

- affected version or commit;
- Windows version and Python version, if relevant;
- reproduction steps that do not destroy personal browser data;
- expected and actual behavior.

## Scope

This application requests administrator privileges and changes filesystem ACLs. Test changes on a disposable browser profile first. Never attach browser databases, logs containing personal paths, or credentials to an issue.
